## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Mwilakabinda/zedcore-innovations.git
```

Navigate into the project:

```bash
cd zedcore-innovations
```

Install the dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

Open the application in your browser at:

```text
http://localhost:3000
```

### Production Build

Create a production build:

```bash
npm run build
```

Then start the production server:

```bash
npm start
```
